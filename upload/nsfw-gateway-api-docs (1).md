## 3. Image-to-Video Tasks

### 3.1 Create a generation task

Create an image-to-video job from an uploaded image resource.

```
POST /web/users/me/models/image2video/tasks?locale=en
```

**Auth:** required (raw JWT in `authorization`).

**Content-Type:** `application/x-www-form-urlencoded`

**Body parameters:**

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| `prompt` | string | yes | Text prompt driving the motion/animation (URL-encoded). |
| `duration` | int | yes | Output duration in seconds (e.g. `5`). |
| `resourceId` | string | yes | ID of the source image resource (from upload). |

**Example request (curl):**

```bash
curl -X POST "https://gateway.nsfwimg2video.com/web/users/me/models/image2video/tasks?locale=en" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -H "authorization: <JWT>" \
  -H "x-device-id: <user-id>" \
  -H "x-time: $(date +%s%3N)" \
  -H "x-country: US" \
  --data-urlencode "prompt=Make her dance" \
  --data-urlencode "duration=5" \
  --data-urlencode "resourceId=3836506534354565357"
```

**Response (HTTP 200):**

```json
{
  "success": true,
  "errorCode": 0,
  "data": {
    "taskId": "3836507620376359457",
    "progress": { "index": 68, "left": "62", "progress": 0 }
  },
  "errorMsg": "OK"
}
```

## 4. Model Catalog (all 5 generation models)

The gateway exposes **5 generation models**. Every model follows the identical task pattern:

```
POST /web/users/me/models/{model}/tasks     -> create task     -> returns taskId
GET  /web/users/me/tasks/{taskId}           -> poll status     -> returns signed video URL
```

The only differences are **what input each model needs** and **what it generates**:

| Model | Endpoint (`/web/users/me/models/.../tasks`) | Input | Output | What it does |

successful task creation queues a real, billable generation job).
